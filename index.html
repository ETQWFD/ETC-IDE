这是一门什么样的语言

自带编译器

come 命令行一键把 .ce 工程编译成 Windows EXE，8 步流水线：词法、语法、语义、代码生成、元数据、交叉编译、UPX 压缩。

生来 root

@grant(root) 直接生成提权清单，程序以系统管理员身份运行；@protect 注入进程保护。

极小编译产物

静态链接后示例 EXE 只有几十 KB，无任何运行库依赖，拷走就能跑。

所有权体系

own / share / move / ptr / ref 编译期检查，防止悬空引用和重复释放。

SIMD 向量

vec2 / vec4 / vec8 原生映射到结构体运算，性能接近手写内联汇编。

图形化 IDE

Win32 原生界面，语法高亮、实时检查、项目树、一键编译，离线自带工具链。

写点什么看看

@grant(root)

const 版本 = "v1.3";
const 作者 = "etc";

fn 阶乘(n: i32) -> i32 {
    if n <= 1 { return 1; }
    return n * 阶乘(n - 1);
}

fn main() {
    println("阶乘(10) =", 阶乘(10));
}

三分钟上手

  1. 下载安装程序，一路下一步装完，勾选携带工具链。
  2. 打开 ETC IDE，新建项目，选 Windows EXE。
  3. 写好 main.ce，点编译，输出目录里就是你的 EXE。
  4. 命令行也行：come demo.exe --oob --proj samples/demo
